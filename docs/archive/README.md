# 歸檔

這裡是**模板建立當時**的設計規格與分階段開發計畫。

- `specs/` — 最初的設計規格書
- `plans/` — 當初分六個階段實作這個模板的工作計畫

## 這裡不是現行規則

內容**保留作為歷史紀錄**,不隨程式碼演進更新,因此與現況必然有出入
(成員拓撲、Bloc/Cubit 判準、check.sh 步驟數等都已經改過)。

現行規則的權威來源是:

- [`docs/architecture.md`](../architecture.md) —— 東西放哪、怎麼連
- [`docs/conventions.md`](../conventions.md) —— 怎麼寫
- [`docs/adr/`](../adr/) —— 為什麼是這樣設計(含後續修訂)

有疑義時以上述三處為準,不要引用本目錄的內容當規則依據。

`tool/check.sh` 的 markdown 連結檢查會跳過本目錄——歷史文件本來就會指向
已經不存在的路徑。
